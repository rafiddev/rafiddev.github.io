# [Rafid Rahman] — Event & Operations Portfolio

A personal site for anyone applying to event, venue, or ticketing-industry
roles — operations, gate/entry, crew, or front-end. It leads with hands-on
event experience (gate security, ticketing-team collaboration, crowd
management) and is upfront about being a beginner front-end developer.
Plain HTML, CSS, and JavaScript — no build step, no frameworks — so it
deploys straight to GitHub Pages.

Swap in your own name, story, and shows and it works for an application
to any company in the space — it isn't tied to one employer.


## What's inside

```
.
├── index.html      # All page content/sections
├── styles.css      # Design system + layout
├── main.js         # Mobile nav, scroll reveal, active link highlight
└── *.jpg           # Show/event photos, referenced directly by filename
```

Sections, top to bottom: Hero, About, Event & Gate Experience, Skills
(Operations + Front-end), What I'm Building (projects), Shows (split into
two tracks — GA Ticket cards for shows you attended as audience, and Crew
Badge cards for shows you volunteered at), Contact.
